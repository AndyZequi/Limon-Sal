# 🍋🧂 Limon & Sal

**Limon & Sal:** es un sitio web dinámico que permite a los usuarios buscar recetas de cocina en tiempo real utilizando la API Ninjas, además de calificar sus recetas favoritas y subir sus propias creaciones culinarias.
El proyecto tiene como propósito ofrecer una experiencia interactiva y amigable para los amantes de la cocina, centralizando recetas de diferentes tipos, países e ingredientes en una sola plataforma intuitiva.

El sitio contará con:
- Un buscador de recetas conectado a la API Ninjas.
- Un sistema de calificación por estrellas para valorar las recetas.
- Una sección donde el usuario puede subir sus propias recetas

## 🚀 Descripción del Proyecto

Desarrollar un sitio web dinámico e interactivo que consuma información de recetas en tiempo real mediante la API Ninjas, permitiendo además que los usuarios califiquen y agreguen sus propias recetas, aplicando principios de diseño responsivo, maquetado moderno y programación front-end.

## 🌐 API Utilizada:

*API Ninjas — Recipe API*

🔗 https://api-ninjas.com/api/recipe

Permite obtener recetas completas mediante peticiones HTTP, filtrando por ingredientes o tipo de platillo.
